# 🚀 Mon Portfolio - Ayoub, Étudiant Développeur Web

Bienvenue sur le code source de mon portfolio ! Ce site vitrine interactif a été conçu pour présenter mon parcours, mes compétences et mes projets de manière fluide et esthétique.

🔗 **[Voir le site en direct](https://ayoubrrj-dev.vercel.app/)**

## ✨ Fonctionnalités clés

- **Design Moderne & Épuré** : Interface minimaliste avec un système de couleurs personnalisé.
- **Interactivité Avancée** : Animations CSS complexes (effet "Liquid Glass" sur la navigation, forme organique animée au survol).
- **Responsive Design** : S'adapte parfaitement à tous les écrans (Mobile, Tablette, Desktop).
- **Formulaire de Contact Fonctionnel** : Envoi d'e-mails en temps réel sans backend (via EmailJS).
- **Téléchargement direct** : Mise à disposition de mon CV en un clic.

## 🛠️ Stack Technique

Ce projet a été construit avec les technologies modernes suivantes :

- **Framework :** [Vue.js 3](https://vuejs.org/)
- **Outil de build :** [Vite](https://vitejs.dev/)
- **Stylisation :** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icônes :** [Lucide Icons](https://lucide.dev/)
- **Service d'E-mail :** [EmailJS](https://www.emailjs.com/)
- **Hébergement :** [Vercel](https://vercel.com/)
